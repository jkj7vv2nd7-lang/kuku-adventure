# 九九アドベンチャー（ククと九九の島）

子ども向け九九学習アプリ。単一ファイル `index.html` だけで動作します（外部ファイル・通信不要、進捗は端末内に保存）。

## v1.1（2026-10-25）改修内容

小学2年生が BALMUDA Phone（4.9インチ／Android 11）で試したフィードバックを受けた改修です。

- **読み上げの不具合修正（Android対策）**：声の読み込み完了を待ってから日本語の声を選ぶ、言語表記（ja-JP／ja_JP）のゆれを吸収、再生直前のキャンセル処理の見直し、音程を自然な 1.0 に変更、連続再生の打ち切りタイマーを廃止。「せってい」と「おぼえる」に **こえの テスト** ボタンを追加
- **さかさま暗唱**：「おぼえる」に「さかさまに きく（9から 1）」と「とめる」を追加。読んでいる行が自動でスクロールして画面内に入り、光ります
- **ひらがな化**：子ども向け画面は原則ひらがなに統一（「届く」→「とどく」など）。九九・段など学習そのものの言葉と、おとな用（保護者画面・認定証）は漢字のまま
- **具体物のイラスト**：丸（●）をやめ、段ごとに あめ・クッキー・いちご・みかん・りんご・ぶどう・ドーナツ・ケーキ・プリン を「おさら」に分けて表示。「3こずつ 4さら： 3＋3＋3＋3 を かぞえてみよう」と、同数累加（同じ数を足していく）で掛け算の意味が伝わる表示にしました。れんしゅう／テストでは「ヒント：おさらを みる」ボタン、間違えた時は自動表示、ちびっこモードでは常時表示
- **小さい画面対応**：クイズ画面を圧縮し、BALMUDA Phone 相当の 360×640 でも「こたえる」ボタンまでスクロールなしで見えるレイアウトに調整。ククの表示も小さくしました

※「自然な声」について：読み上げは端末の音声合成（Google の日本語音声など）を使うため、声質は端末側の設定に左右されます。声が出ない場合は、端末の「せってい」で Google の日本語読み上げ音声が入っているかご確認ください（アプリ内の案内文も参照）。

## GitHub Pages で公開する手順（更新も同じ）

1. リポジトリ `kuku-adventure` の画面で **Add file → Upload files** を選ぶ
2. この ZIP の中身（`index.html` と `README.md`）をアップロードし、既存ファイルを上書きして Commit
3. 数分待つと、公開URLに新しい内容が反映されます

公開URL： https://jkj7vv2nd7-lang.github.io/kuku-adventure/

スマホでそのURLを開き、ブラウザの「ホーム画面に追加」をするとアプリのように起動できます。
※ 更新が反映されない時は、ブラウザのキャッシュが残っていることがあります。少し時間をおくか、再読み込みしてください。進捗データは端末のブラウザ内に保存され、index.html を差し替えても消えません。

## 使い方メモ

- 初回はプロフィールのタマゴをタップして「クク」を孵化させます
- 音声入力（🎤）はブラウザ依存です。Chrome（Android）などで動作し、非対応環境では自動的に数字タップ入力のみになります
- 読み上げは端末の音声合成（日本語）を使います。声が出ない場合は端末の音量と、アプリ内「せってい」の「ククの こえ」と「こえの テスト」を確認してください
- 進捗データは各端末のブラウザ内に保存されます。端末を変えると引き継がれません
